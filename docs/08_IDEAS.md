# Lumina Idea Vault

**Last updated:** August 29, 2026

Ideas are hypotheses, not current capabilities or commitments. Log them here
before changing the product. Promote an idea into the roadmap only after user
behavior or repeated feedback supports it.

The canonical staged direction lives in `14_LONG_TERM_VISION.md`.

---

## Near-Term Experiments

- [ ] Profile-completeness guidance that tells professionals exactly what is missing
- [ ] A clearer separation between the professional dashboard and public profile
- [ ] A clearer request explanation: discuss service details and availability; no charge yet
- [ ] An obvious feedback and issue-reporting path for beta users
- [ ] A small Results V1: choose Single Photo or Before & After, select the
      service, and add optional context
- [ ] Measure whether clients interact with or mention structured service results

Before-and-after pairs in V1 would be labeled **professional-submitted**. Do not
call them verified merely because two images were uploaded.

---

## Data-Backed Reputation Signals

Show these only when Lumina can calculate them accurately:

- [ ] Typical response time
- [ ] Completed Lumina services
- [ ] Verified-review count and rating
- [ ] Repeat-client count or percentage

Future verification programs require defined criteria and operating processes:

- [ ] Identity verification
- [ ] License verification where applicable
- [ ] Completed-service-linked result
- [ ] Client-confirmed result with consent

Avoid decorative labels such as “Top Rated,” “Trusted Artist,” or “Verified
Professional” unless the criteria are transparent and consistently enforced.

## Questions Before Promoting an Idea

1. What repeated problem does this solve?
2. Does it strengthen trust or simply add activity?
3. What exact claim will the interface make, and can Lumina prove it?
4. Can a smaller experiment test the assumption?
5. What result would justify keeping or expanding it?
