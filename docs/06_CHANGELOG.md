## August 2026 — Private-Beta Release

### Trust, requests, and reviews

- Completed the request → proposal → client confirmation → appointment → completion lifecycle
- Added professional-controlled completion for confirmed appointments
- Added verified-review access after appointment completion
- Added authenticated reviewer names and professional review responses
- Enforced one review per completed appointment
- Added database protections against unauthorized completion and anonymous or unverified reviews
- Fixed completed-appointment review links and review-form opening
- Added clearer completed-service states and review calls to action

### Messaging, realtime, and notifications

- Added realtime request-linked conversations
- Added Enter to send and Shift + Enter for a new line on desktop
- Added send-in-progress controls and message-input focus improvements
- Added realtime request and message updates
- Added unread states that clear while a conversation is open
- Added participant names and profile context to notifications
- Added notification clearing and image sharing

### Request organization

- Added active and archived request views
- Added hide and unhide controls for both clients and professionals
- Added clearer proposal, confirmation, and completion states
- Added live status labels and notification-driven request navigation

### Client accounts

- Added client profile editing and account settings
- Added settings and privacy navigation
- Clarified that saved professionals belong to client accounts
- Improved account menus, navigation, and responsive styling

### Professional accounts

- Separated profile editing from settings and privacy
- Added services, portfolio, availability, and request-management shortcuts
- Added clearer professional identity, business-name, booking-link, and contact fields
- Added structured experience and location information
- Added salon, home-studio, mobile-salon, and travel-based work types
- Added clearer ownership context when a professional views their public profile

### Authentication and email

- Added forgot-password and secure password-reset pages
- Fixed production reset redirects
- Connected Resend for production authentication email delivery
- Added branded authentication emails and time-limited reset links
- Added device-session security controls

### Homepage, discovery, and responsive design

- Refined desktop, tablet, and mobile homepage layouts
- Added a rotating featured-service showcase with accurate service destinations
- Added mobile swipe, desktop drag, and trackpad gesture support
- Improved mobile search, navigation, spacing, and artist cards
- Added outside-click closing for browse filters and sort menus
- Refined section spacing and responsive intermediate-width behavior

### Brand and production

- Added Lumina site metadata, primary logo, and browser icons
- Verified the production domain at joinlumina.co
- Completed a successful production build covering 28 routes

### Business and operating documents

- Added the private-beta feedback log
- Added English and Vietnamese business overviews
- Added product principles and the founder notebook
- Documented Lumina's intermediation model and business value
