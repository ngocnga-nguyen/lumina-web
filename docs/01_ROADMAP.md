# Lumina Product Roadmap

---

# V1 — Launch

Goal:

Release a polished MVP that allows real artists and clients to successfully discover each other, communicate, and complete booking requests.

## Core Platform

- User accounts
- Artist profiles
- Browse artists
- Search
- Map
- Saved artists
- Compare artists
- Portfolio
- Services
- Client requests
- Artist proposals
- Messaging
- Image sharing
- Notifications
- Hide/archive requests

## Polish

- Empty states
- Better loading states
- Consistent spacing
- Better mobile experience
- Error handling
- Success messages
- Performance improvements

## Launch Goal

Invite the first 20–50 artists.

Collect feedback.

Improve based on real usage.

---

# V2 — Growth

Goal:

Help clients discover better artists while helping artists build trust.

## Trust

- Verified portfolios
- Verified reviews
- Repeat client percentage
- Response time
- Last active
- Years experience
- Featured artists

## Discovery

- Better filters
- Trending artists
- Recently joined
- Popular near you
- Personalized recommendations

## Collections

- Wedding inspiration
- Vacation
- Birthday
- Nails
- Hair
- Skincare

# V3 — Marketplace

Goal:

Become the platform clients naturally open before booking beauty services.

## Booking

- Appointment scheduling
- Calendar sync
- Availability
- Booking confirmations

## Reviews

- Multi-category ratings
- Before & after uploads
- Client photos

## Communication

- Voice notes
- Message reactions
- Replies
- Typing indicator

# V4 — Professional Tools

Goal:

Help artists grow their businesses.

Possible features

- Analytics
